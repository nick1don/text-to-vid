# AI Talking-Head Video Generator

> Built with [Claude Code](https://claude.ai/code).

Generate polished short-form videos with a synchronized talking head, voiceover, and animated code background — all from a photo and a few lines of text.

**What it produces:**
- Animated dark background with drifting LLM code snippets (cycles every 5 seconds)
- Centered text beats that fade in and out in sync with the audio
- A lip-synced talking head in the bottom-right corner, generated from your photo
- Deep AI voice narration via ElevenLabs
- A single composited 1280×720 MP4, ready to share

## How it works

```
Photo + Script
      │
      ├─► ElevenLabs  →  voiceover MP3/WAV
      │
      ├─► D-ID /talks  →  lip-synced talking-head MP4
      │
      └─► PIL + MoviePy  →  animated background frames
                                    │
                                    └─► CompositeVideoClip  →  final.mp4
```

1. **ElevenLabs** converts your spoken text to natural-sounding audio (Brian voice by default — deep and resonant).
2. **D-ID** animates your photo to match the audio, with `pad_audio: 0.5` so the face starts neutral (no open-mouth thumbnail).
3. **PIL** renders every frame of the background: a dark canvas with cyan monospace code snippets that drift and crossfade every 5 seconds, a grid overlay, pulsing accent line, and the beat text centered on screen.
4. **MoviePy** composites background + talking head + audio into the final video.

Each step caches its output — re-running only regenerates what's missing.

## Requirements

- Python 3.10+
- An [ElevenLabs](https://elevenlabs.io) API key
- A [D-ID](https://www.d-id.com) API key (`email:key` format)
- `ffmpeg` installed and on your PATH

## Setup

```bash
git clone https://github.com/yourhandle/ai-talking-head-video
cd ai-talking-head-video

pip install -r requirements.txt

cp .env.example .env
# edit .env and add your API keys
```

Export your keys before running (or use a tool like `direnv`):

```bash
export ELEVENLABS_API_KEY=sk_...
export D_ID_API_KEY=you@email.com:yourkey
```

## Usage

**1. Add your photo**

Place a square PNG of the speaker at `output/narrator.png`. Cropped face shots work best with D-ID.

```bash
mkdir -p output
cp your_photo.png output/narrator.png
```

**2. Edit the script content**

Open `generate.py` and update the `BEATS` and `SPOKEN_TEXT` near the top:

```python
BEATS = [
    "First on-screen card\nline two",
    "Second card",
    "Third card — longer text\ncan span multiple lines",
    "Sign-off\n— Your Name",
]

SPOKEN_TEXT = """\
Your full voiceover script goes here.
It will be read aloud by ElevenLabs.
"""
```

**3. Run**

```bash
python generate.py
```

Output lands at `output/final.mp4`.

To regenerate the repo demo video (uses the same pipeline):

```bash
python make_demo.py
```

## Customization

| What | Where | Notes |
|------|-------|-------|
| Voice | `ELEVENLABS_VOICE_ID` | Any ElevenLabs voice ID |
| Voice style | `VOICE_SETTINGS` | Adjust `stability` / `similarity_boost` |
| Resolution | `W, H` | Default 1280×720 |
| Colors | `BG_COLOR`, `ACCENT_COLOR` | RGB tuples |
| Code snippets | `CODE_POOL` | Swap in whatever fits your context |
| Screen swap rate | `SCREEN_INTERVAL` | Seconds between background swaps |
| Talking head size | `thumb_w = int(W * 0.28)` | Fraction of total width |
